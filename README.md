# ScheduleGen project page

Project website for **ScheduleGen: Demonstration Generation via Skill Scheduling for Multi-Arm Imitation Learning**.

Neel Jawale, Stephan Pleines, Soha Pouya, Yuke Zhu, Ajay Mandlekar, Caelan Garrett.

- Website: https://njawale42.github.io/ScheduleGen/
- Paper: https://arxiv.org/abs/2610.39429

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8000/>.

## Deployment

GitHub Pages should be configured to deploy from the `main` branch and the repository root. The site intentionally has no build step or external runtime dependencies.
